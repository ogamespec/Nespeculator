## Not defects (checked so they are not re-filed)

- `HDL/PPU/pamux.v` (`PamuxHighBit`/`PamuxLowBit`) — the comment "the .circ Constant with no
  value attribute defaults to 1 in Logisim-Evolution" is **correct** for the
  v3.8.0 file in this tree (see finding 1); it is the load-bearing precedent for
  the convention, not a workaround to undo.
- `Docs/6502/6502 Instruction Set.htm` — the imprecise spelling `zpg`/`rel` and
  the "cyles" column header are cosmetic; only the five wrong *values* in
  finding 6 mislead.
- `HDL/PPU/Readme.md` — the status line already says PAL / OAM / CRAM timing
  "still need refinement"; it does not claim the model is die-perfect, so the
  `tilecnt.v` defect does not contradict the Readme's own claim.
